위험과 남은 문제

  • 보통키트를 고치면서 하네스를 7번 다시 이어 실행한 기록. 사람의 개입 없이 처음부터 끝까지 실행한 적은 아직 없음
  • 보통Netlify 와 GitHub 저장소가 연결되지 않아 푸시해도 자동 배포가 되지 않음
  • 낮음배포본 첫 검사의 시간 초과 원인은 확인하지 않음. 다시 검사에서는 통과
