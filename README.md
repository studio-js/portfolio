# 김지성 포트폴리오

<https://studio-js.github.io/portfolio/> 의 배포본입니다. 사이트 소스에서 빌드한 정적 파일만 들어 있습니다.

| 파일 | 화면 |
|---|---|
| `index.html` | 첫 화면(업무 자동화, 프로젝트, 스킬과 파이프라인, 경력, 연락처) |
| `lms.html` | 사내 LMS 개발과 운영 |
| `knowledge.html` | AI 뉴스 지식 구축 에이전트 |
| `data.html` | 해커톤 실습용 합성 데이터 |
| `tools.html` | 직접 만든 스킬과 파이프라인 |

`robots.txt` 와 화면마다 넣은 `noindex` 로 검색 엔진의 수집을 막습니다.
