전후 비교

문체 검수 스킬

에이전트가 쓴 교안을 검수하면서 직접 지적한 표현 120건을 33종류로 분류해 체크리스트로 만들었습니다. 수정 에이전트가 이 체크리스트에 따라 고치고 검수 에이전트가 원문과 대조합니다.

같은 교안 3편을 이전 방식⁠(외부 윤문 스킬)⁠과 새 방식으로 각각 고쳐 비교한 뒤 새 방식을 채택했습니다.

이전 방식새 방식
고친 글에 남은 검사 위반같은 교안 3편을 방식별로 따로 고친 결과
이전 방식 9건새 방식 1건
검수 에이전트가 고쳐야 한다고 표시한 곳
이전 방식 72곳새 방식 39곳
글 1편에 쓴 토큰에이전트 호출은 4번에서 3번으로 감소
이전 방식 약 82만새 방식 약 71만

다이어그램 스킬

matplotlib의 기본 설정으로는 한글이 네모로 깨집니다. 이 스킬은 한글 글꼴을 고르고 그림을 저장할 때 글자와 선이 겹치는지 검사해서 겹치면 저장하지 않습니다.

교안 검수 에이전트

수강생 역할의 에이전트가 교안을 처음부터 읽고 막힌 곳을 표시합니다. 표시된 곳을 고치고 다시 읽게 하는 과정을 반복했습니다.

교차 검증 스킬

Claude가 쓴 초안을 GPT와 DeepSeek 계열의 검토 에이전트가 각각 검토하고 그 검토 의견을 반영해 다시 구현합니다. 함수 하나를 과제로 정해 같은 테스트 14건으로 채점했습니다.

단독 초안교차 검증
통과한 테스트⁠(14건 가운데)단독 초안은 잘못된 입력 5개를 오류로 처리하지 못함
단독 초안 9건교차 검증 14건

개발 환경 가드레일 훅

에이전트가 실행하려는 셸 명령과 MCP 도구 호출을 훅이 먼저 검사합니다. 차단 항목에 해당하면 실행을 막고 차단 사유를 에이전트에게 반환합니다.

권한 제한과 가드레일

이름하는 일쓰는 곳
개발 환경 가드레일 훅.env 읽기, PR 병합, 로컬 Docker 실행을 차단. 테스트 케이스 158건으로 검증LMS 개발 환경
키트 가드레일 훅과 Stop 훅시크릿 접근, 테스트 변조, 보호 리소스 접근, 파괴적 명령을 차단. 테스트가 통과할 때까지 에이전트의 종료를 막음LMS 개발 에이전트 키트
뉴스 에이전트 가드레일 훅역할별로 시크릿 접근을 제한하고 발행 전 검사를 통과한 호출만 허용AI 뉴스 지식 구축 에이전트
파일 편집 도구를 뺀 검수 에이전트교안을 검수하는 에이전트에는 파일 편집 도구를 주지 않음교안 제작
개인정보 보호 프롬프트 지침모든 서브에이전트 프롬프트에 개인정보를 외부 요청에 넣지 않는다는 지침을 포함교안 제작, 합성 데이터

검증과 평가

이름하는 일쓰는 곳
수용 테스트 우선 작성평가 에이전트가 구현보다 먼저 테스트를 쓰고 하네스가 그 테스트를 직접 실행LMS 개발 에이전트 키트
교안 린터노트북의 규격, 문체, 분량, 그림을 검사. 검사 함수 227개교안 제작
교안 검수 에이전트수강생과 교수자의 역할로 교안을 읽고 막힌 곳을 표시교안 제작
발행 전 검사자료의 구조, 수치, 빈 그림을 검사해 하나라도 걸리면 발행 중단AI 뉴스 지식 구축 에이전트
독립 검증과 블라인드 분석파일 편집 도구를 뺀 에이전트가 검증 항목의 값을 다시 계산. 정답표를 받지 않은 에이전트가 분석합성 데이터 생성
