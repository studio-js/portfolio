업무 자동화 지도

데이터 직무 부트캠프의 과정을 설계하고 강의하면서 맡은 나머지 업무를 Claude Code 에이전트 워크플로로 자동화했습니다. 워크플로마다 요구 사항과 기준을 직접 정하고 단계 결과를 승인했습니다.

업무 프로세스 표준화

워크플로마다 사람이 확인하는 시점과 결정을 남기는 곳이 달랐습니다. 워크플로 4개의 단계, 담당 에이전트, 자동 검사, 사람이 확인할 항목을 같은 형식의 정의 파일로 정리했습니다.

승인 기록은 사람이 터미널에서 실행한 명령으로만 남습니다. 에이전트가 도구 호출로 이 기록을 쓰거나 승인 명령을 실행하면 가드레일 훅이 막습니다. 승인 기록에는 보고서의 해시를 남겨 승인한 뒤 보고서가 바뀌면 다음 단계가 다시 막힙니다.

확인 항목 50개 가운데 18개는 운영에서 사람이 하던 확인이고 32개는 새로 정했습니다. AI 뉴스는 발행 전에 사람이 승인하는 단계가 없어서 확인 항목 11개 가운데 10개를 새로 정했습니다.

보고서 전체 보기(새 창)
